# Individual household electric power consumption

Creators: Georges Hebrail and Alice Berard. Repository: University of California,
Irvine, DOI 10.24432/C58K54. License: CC BY 4.0. The semicolon-delimited text file
is the exact qualified ZIP member; no measurement values have been transformed.

This source contains minute measurements from one household in Sceaux, France.
`Date` uses day/month/year and `Time` uses hour:minute:second. `Global_active_power`
and `Global_reactive_power` are minute-averaged kW and kVAR respectively. `Voltage`
is minute-averaged volts; `Global_intensity` is minute-averaged amperes.
`Sub_metering_1`, `Sub_metering_2`, and `Sub_metering_3` report watt-hours for the
minute. The source describes missing measurements; inspect the supplied raw
labels rather than assuming that every nonempty value is numeric. No timezone
conversion has been applied.
